# AlphaChess

A chess engine who is better than dhgf.

## Getting Started

### **Client**

```bash
cd client
pnpm dev
```

### **Server**

```bash
cd server
cargo run
```

### **Engine**

To test the engine, run

``` bash
cargo test
```

Run self-play with

``` bash
cargo play
```

Play against Stockfish with

``` bash
cargo stockfish
```
